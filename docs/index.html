TomoMerge

Blend two overlapping inversions into one map. Shared nodes become a Gaussian distance-weighted average that trusts whichever array centre is nearer; nodes only one map has pass through untouched. Drop two files and the answer is already on screen.

About this softwareWhat it does, and what a good merge looks like

Two overlapping tomographic maps go in; one map comes out. Nodes that only one map covers are passed through untouched. Where both maps cover the same node they disagree, and the tool replaces that node with a weighted average that trusts whichever array centre is nearer. The only real choice is how wide the hand-over between them should be — and getting it wrong writes a seam into your map that looks like structure.

Drop your own two files below and the tool computes the largest safe hand-over width for them, reports the residual step in km s−1, and turns its verdict red if you push past it. The six-panel figure above is generated for your data and can be downloaded.
